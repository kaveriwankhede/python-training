About Study Quiz Hub

Study Quiz Hub is an interactive learning platform developed using Python Flask, HTML5, CSS3, Bootstrap, JavaScript, SQLite, and Jinja2 Templates. It helps students learn programming through theory notes, MCQ quizzes, automatic result generation, performance tracking, and interview preparation.
