📘 Introduction

C++ is an Object-Oriented Programming Language developed by Bjarne Stroustrup. It is an extension of the C programming language.

📜 History

C++ was developed by Bjarne Stroustrup in 1979 at Bell Labs.

⭐ Features

  • Object-Oriented
  • Fast Execution
  • Platform Independent
  • Reusable Code
  • Secure

🏛️ Classes & Objects

A Class is a blueprint for creating objects. An Object is an instance of a class.

📊 Data Types

  • int
  • float
  • char
  • double
  • bool

📦 Variables

int age = 20;
string name = "Kaveri";

➕ Operators

  • Arithmetic
  • Relational
  • Logical
  • Assignment

🧬 Inheritance

Inheritance allows one class to acquire the properties and methods of another class.

🔄 Polymorphism

Polymorphism allows one function to perform different tasks based on the object.

🔒 Encapsulation

Encapsulation means wrapping data and methods into a single unit called a class.

🎯 Abstraction

Abstraction hides implementation details and shows only the essential features.

  • Primary Key
  • Foreign Key
  • Candidate Key
  • Alternate Key
  • Composite Key

    id INT,
    name VARCHAR(50)
);

🖥️ OS Topics
📘 Introduction ⚙️ Functions 📂 Types of OS 🔄 Process 🧵 Thread 💻 CPU Scheduling ⛔ Deadlock 💾 Memory Management 📄 Paging 🔒 Security

📘 Introduction

An Operating System (OS) is system software that acts as an interface between the user and computer hardware.

⚙️ Functions of Operating System

  • Process Management
  • Memory Management
  • File Management
  • Device Management
  • Security

📂 Types of Operating System

  • Batch OS
  • Time Sharing OS
  • Distributed OS
  • Network OS
  • Real-Time OS

🔄 Process

A Process is a program in execution.

🧵 Thread

A Thread is the smallest unit of execution inside a process.

💻 CPU Scheduling

  • FCFS
  • SJF
  • Priority Scheduling
  • Round Robin

⛔ Deadlock

Deadlock occurs when two or more processes wait indefinitely for resources held by each other.

💾 Memory Management

Memory Management controls and coordinates computer memory efficiently.

📄 Paging

Paging is a memory management technique that divides memory into pages and frames.

🔒 Security

Operating System provides authentication, access control, and protection against unauthorized access.

🌳 Complete Data Structure Theory Notes 🌳
========================================

🌳 Data Structure Topics
📘 Introduction 📂 Types of Data Structure 📚 Array 🔗 Linked List 📦 Stack 🚶 Queue 🌳 Tree 🕸️ Graph 🔍 Searching 🔄 Sorting ⏱️ Time Complexity

📘 Introduction

Data Structure is a method of organizing and storing data efficiently so that it can be accessed and modified easily.

📂 Types of Data Structure

  • Linear Data Structure
  • Non-Linear Data Structure

📚 Array

An Array is a collection of elements of the same data type stored in contiguous memory locations. 

int arr[5] = {10,20,30,40,50};

🔗 Linked List

A Linked List is a linear data structure where each node contains data and a pointer to the next node.

📦 Stack

Stack follows the LIFO (Last In First Out) principle.

🚶 Queue

Queue follows the FIFO (First In First Out) principle.

🌳 Tree

A Tree is a hierarchical data structure consisting of nodes connected by edges.

🕸️ Graph

A Graph is a collection of vertices (nodes) and edges used to represent relationships.

🔍 Searching

  • Linear Search
  • Binary Search

🔄 Sorting

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort

⏱️ Time Complexity

Time Complexity measures the execution time of an algorithm. It is represented using Big O Notation.

  • O(1)
  • O(log n)
  • O(n)
  • O(n log n)
  • O(n²)

  • Narrow AI
  • General AI
  • Super AI

Machine Learning is a subset of AI that allows computers to learn from data without being explicitly programmed.

🕸️ Deep Learning

Deep Learning uses neural networks with multiple layers to solve complex problems such as image and speech recognition.

💬 Natural Language Processing

NLP enables computers to understand, process and generate human language.

👁️ Computer Vision

  • Healthcare
  • Recommendation Systems
  • Face Recognition

  • Fast Decision Making
  • Automation

  • Data Breach

  • Worm
  • Trojan Horse
  • Spyware
  • Adware
