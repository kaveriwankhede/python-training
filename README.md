# 📚 Study Quiz Hub

### AI-Powered Interactive Learning & Assessment Platform

> **Study Quiz Hub** is a modern learning platform that combines interactive quizzes, AI-powered assistance, performance analytics, interview preparation, and personalized learning tools in one place.

Built with **Python, Flask, SQL, HTML, CSS, JavaScript, and AI API integration**, the platform is designed to make technical learning more interactive, practical, and personalized.

---

## 🎯 Why Study Quiz Hub?

Learning, practicing questions, analyzing mistakes, and preparing for interviews often requires multiple platforms.

**Study Quiz Hub brings these activities together in a single platform.**

It helps learners:

* 📖 Practice technical subjects
* 🧠 Get AI-powered assistance
* 📊 Track learning performance
* ❌ Understand incorrect answers
* 🎯 Prepare for technical interviews
* 🗺️ Follow structured learning plans
* 💻 Practice programming through coding challenges

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Study-Quiz-Hub
```

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 3️⃣ Activate Environment

**Windows PowerShell**

```powershell
venv\Scripts\Activate.ps1
```

### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 🔐 Environment Configuration

Create a `.env` file:

```env
SECRET_KEY=your_secret_key
GROQ_API_KEY=your_groq_api_key
```

⚠️ **Never upload API keys, passwords, secret keys, or `.env` files to GitHub.**

---

## ▶️ Run the Application

Start the Flask application:

```bash
python app.py
```

Open your browser:

```text
http://127.0.0.1:5000/
```

> If your main Python file has a different name, use that filename instead of `app.py`.
